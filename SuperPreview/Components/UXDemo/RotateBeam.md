# Rotate Beam 卡片

入口：组件库列表最后的「Rotate Beam 环绕光效」。

源码：同目录 `RotateBeamDemoView.swift`。独立实现，仅参考环绕光束的视觉概念，没有复制 Libraries.dev 源码，没有新增依赖。

## 视觉与实现

- 空白卡片最大宽度 330pt、高度 210pt、圆角 24pt；窄屏自动缩小，无文字或图标。
- 页面背景、卡片底色、标题、辅助文字和基础描边均使用 Assets.xcassets 中已有的明暗色对，随系统黑白主题自动切换。
- 静止的圆角矩形上叠加 AngularGradient 描边，渐变角度每 4 秒旋转一周。光束依次经过红、橙、金、绿、蓝、紫，最后保持白色高光收束。
- 光效由清晰边缘、近光、中光和宽外环组成；「光晕扩散」通过调整两层 Blur 半径扩大光晕面积。
- 「发光强度」单独控制光晕层的透明度，「透明度」控制整束 Beam；扩散范围为 0.25×–10×。
- 卡片下方提供实时参数面板：透明度、发光强度、光束宽度、光晕扩散、拖尾长度和旋转周期。颜色保持固定为当前彩虹方案，所有滑块修改都会立即传入光效。
- 旋转的是光场，卡片和边框形状不旋转。采用匀角速度，光头沿长方形边缘的线速度并非恒定。
- TimelineView 只更新光效子视图，刷新间隔至少 1/60 秒；页面消失和后台时暂停计时，回来继续；系统减少动态效果开启时使用静态高光。
- UIKit SceneDelegate 宿主通过 UIApplication 当前状态与激活/失活通知控制时钟；页面出现即启动，避免依赖未正确传递的 SwiftUI scenePhase。计时函数显式接收运行状态，避免刚写入状态后再读取造成启动不一致。
- 光效不拦截点击，并从辅助功能树中隐藏。不要在 overlay 之后裁切，否则会切掉外光。

## 复用

```swift
CardView()
    .overlay {
        RotateBeamBorder(cornerRadius: 24, duration: 4)
    }
```

圆角应与宿主卡片一致。演示使用深色画布以突出光晕。实现沿用项目 iOS 18 部署目标，不需要 Metal 或外部资源。

## 验证

构建后从组件库最后一个入口进入，观察光头连续跨越四个圆角及循环接缝；返回列表或切换后台后再进入检查恢复；开启系统「减少动态效果」检查静态高光。
